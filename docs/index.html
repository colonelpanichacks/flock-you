Flock You

WiFi & BLE Probe / Deauth Detector — ESP32 Web Flasher

Select Firmware

Requires Chrome / Edge on desktop. Connect ESP32 via USB.

Requirements

  • Chrome or Edge browser (desktop)
  • ESP32 connected via USB-C/USB-A cable
  • No drivers needed on modern OS
  • Approximately 1.5 MB free flash on device

Quick Start

  1. Select your board variant above
  2. Click Install and select the correct COM/tty port
  3. Wait ~60 s for flash + verify to complete
  4. Open Serial Monitor at 115200 baud to see detections
  5. Switch to the Live Dashboard tab above for real-time visualization

What It Detects

Flock You passively scans for WiFi probes deauth frames BLE trackers pwnagotchi OUI fingerprinting and emits structured JSON on serial for wardriving / logging.

Outputs: {"event":"detection","detection_method":"OUI","mac_address":"xx:xx:xx","rssi":-72,...}
